
# Artificial Neural Networks (ANN) – Practice & Concepts

This folder contains **step-by-step Jupyter notebooks** covering **Artificial Neural Networks (ANN)** concepts, starting from the basic perceptron to advanced optimization and regularization techniques.  
The notebooks focus on **theory + intuition + practical implementation using Python and Keras**.


---

## 📘 Notebook Descriptions

### 🔹 Fundamentals (Notebooks 01-03)

| Notebook | Description |
|----------|-------------|
| **01-perceptron-trick.ipynb** | Understanding the perceptron trick algorithm and decision boundaries for binary classification |
| **02-loss-function-perceptron.ipynb** | Exploring the role of loss functions in perceptron learning and model training |
| **03-problem-with-perceptron.ipynb** | Identifying limitations of single-layer perceptrons (e.g., XOR problem) and the need for deep networks |

### 🔹 Real-World ANN Applications (Notebooks 04-06)

| **06-graduate-admission-regression.ipynb** | Regression problem using ANN to predict graduate admission chances |
