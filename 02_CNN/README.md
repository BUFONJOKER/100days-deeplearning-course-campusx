# 🧠 Convolutional Neural Networks (CNN) – Keras & TensorFlow

This repository contains my **hands-on practice notebooks, experiments, and visual resources** related to **Convolutional Neural Networks (CNNs)** using **Keras (TensorFlow backend)**.  
It covers **core CNN concepts, classic architectures, transfer learning, data augmentation, and the Keras Functional API**.

---

## 📚 Topics Covered

- ✅ Padding & Pooling
- ✅ CNN Architecture Basics
- ✅ LeNet Architecture
- ✅ Image Classification (Dog vs Cat)
- ✅ Data Augmentation
- ✅ Pretrained Models
- ✅ Transfer Learning  
  - Feature Extraction  
  - Feature Extraction + Data Augmentation  
  - Fine-Tuning
- ✅ Keras Functional API  
  - Single Input → Multiple Outputs  
  - Multiple Inputs → Single Output  
  - Transfer Learning with Functional API
